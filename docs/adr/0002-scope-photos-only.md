# Scope: still photographs only

Explicit "no"s to keep the project from sprawling: no video, no live webcam, no identification of people (only "there is a face here", never "this is Alice"), no native mobile app. In scope: still photos (JPEG/PNG/WebP/HEIC), one at a time or as a Batch, with automatic Detection and manual Region editing.
